# Automation Use Case Examples

One worked example for each standard use case on the website. Each folder has a `README.md` (scenario, before and after, automated flow, rules), a sample input file, and the expected output.

| # | Use case | Folder |
|---|---|---|
| 1 | Data quality checks | `01-data-quality-checks` |
| 2 | Reporting workflows | `02-reporting-workflows` |
| 3 | Invoice & document processing | `03-invoice-document-processing` |
| 4 | Data entry & system updates | `04-data-entry-system-updates` |
| 5 | Reconciliations | `05-reconciliations` |
| 6 | Email & request handling | `06-email-request-handling` |
| 7 | Onboarding & offboarding | `07-onboarding-offboarding` |
| 8 | Monitoring & alerts | `08-monitoring-alerts` |
| 9 | Web & application data extraction | `09-web-data-extraction` |

All data is fictional. Time and savings figures are illustrative, so replace them with real numbers for each client.
